# Docker镜像本地构建完整指南

## 📦 什么是Docker镜像？

**Docker镜像**就像是一个"软件安装包"，它包含了：
- ✅ 操作系统环境（如Linux）
- ✅ 运行环境（如Python、Node.js）
- ✅ 应用程序代码
- ✅ 所有依赖库
- ✅ 配置文件

**简单理解**：
- 🏠 **镜像** = 房子的设计图纸（模板）
- 🏡 **容器** = 根据图纸建好的房子（运行实例）
- 一个镜像可以创建多个容器

**为什么需要镜像？**
- 📦 打包所有依赖，避免"在我机器上能跑"的问题
- 🚀 快速部署，一键启动
- 🔒 环境隔离，不影响主机系统
- 📋 版本管理，可以保存不同版本的镜像

---

## 🏗️ 本项目镜像结构

这个项目有**3个镜像**需要构建：

### 1. **server-base镜像**（基础镜像）
- 📋 包含：Python 3.10 + 系统依赖 + Python包
- 🎯 用途：作为server镜像的基础
- 📁 文件：`Dockerfile-server-base`

### 2. **server镜像**（Python应用）
- 📋 包含：应用代码（xiaozhi-server目录）
- 🎯 用途：运行Python语音助手服务
- 📁 文件：`Dockerfile-server`
- ⚠️ **依赖**：需要先构建server-base镜像

### 3. **web镜像**（Web管理界面）
- 📋 包含：Vue前端 + Java后端 + Nginx
- 🎯 用途：提供Web管理界面（智控台）
- 📁 文件：`Dockerfile-web`

### 步骤一：构建server-base镜像（必须先构建）

**为什么先构建base？**
- `Dockerfile-server` 依赖 `server-base` 镜像
- base镜像包含所有Python依赖，构建较慢
- 分离后可以复用，加快后续构建

```bash
# 在项目根目录执行
docker build -t xiaozhi-esp32-server:server-base -f ./Dockerfile-server-base .
```

**构建过程说明：**
1. 📥 下载Python 3.10基础镜像
2. 🔧 安装系统依赖（ffmpeg、libopus0等）
3. 📦 安装Python包（从requirements.txt）
4. ⏱️ **预计时间：10-30分钟**（取决于网络速度）

**构建成功标志：**
```
Successfully built xxxxxx
Successfully tagged xiaozhi-esp32-server:server-base
```

---

### 步骤二：构建server镜像（应用镜像）

```bash
# 在项目根目录执行
docker build -t xiaozhi-esp32-server:server_latest -f ./Dockerfile-server .
```

**构建过程说明：**
1. 📥 使用刚才构建的server-base镜像
2. 📋 复制应用代码（main/xiaozhi-server目录）
3. ⏱️ **预计时间：1-3分钟**

**如果报错找不到base镜像：**
```
Error: pull access denied for ghcr.io/xinnan-tech/xiaozhi-esp32-server:server-base
```
**解决方法：** 修改 `Dockerfile-server` 第2行：
```dockerfile
# 修改前：
FROM ghcr.io/xinnan-tech/xiaozhi-esp32-server:server-base

# 修改后：
FROM xiaozhi-esp32-server:server-base
```

---

### 步骤三：构建web镜像（Web管理界面）

```bash
# 在项目根目录执行
docker build -t xiaozhi-esp32-server:web_latest -f ./Dockerfile-web .
```

**构建过程说明：**
1. 📦 构建Vue前端（npm install + npm run build）
2. ☕ 构建Java后端（mvn clean package）
3. 🚀 打包成最终镜像（Nginx + JAR包）
4. ⏱️ **预计时间：5-15分钟**

## 🔧 修改docker-compose使用本地镜像

构建完成后，需要修改 `docker-compose_all.yml` 使用本地镜像：

### 修改前（使用远程镜像）：
```yaml
xiaozhi-esp32-server:
  image: ghcr.nju.edu.cn/xinnan-tech/xiaozhi-esp32-server:server_latest

xiaozhi-esp32-server-web:
  image: ghcr.nju.edu.cn/xinnan-tech/xiaozhi-esp32-server:web_latest
```

### 修改后（使用本地镜像）：
```yaml
xiaozhi-esp32-server:
  image: xiaozhi-esp32-server:server_latest

xiaozhi-esp32-server-web:
  image: xiaozhi-esp32-server:web_latest
```

## 📝 完整构建脚本（一键构建）

创建 `build-local.sh`（Linux/Mac）或 `build-local.bat`（Windows）：

### Windows版本（build-local.bat）：
```batch
@echo off
echo ========================================
echo 开始构建Docker镜像
echo ========================================

echo.
echo [1/3] 构建server-base镜像...
docker build -t xiaozhi-esp32-server:server-base -f ./Dockerfile-server-base .
if %errorlevel% neq 0 (
    echo 构建server-base失败！
    exit /b 1
)

echo.
echo [2/3] 构建server镜像...
docker build -t xiaozhi-esp32-server:server_latest -f ./Dockerfile-server .
if %errorlevel% neq 0 (
    echo 构建server失败！
    exit /b 1
)

echo.
echo [3/3] 构建web镜像...
docker build -t xiaozhi-esp32-server:web_latest -f ./Dockerfile-web .
if %errorlevel% neq 0 (
    echo 构建web失败！
    exit /b 1
)

echo.
echo ========================================
echo ✅ 所有镜像构建完成！
echo ========================================
echo.
echo 镜像列表：
docker images | findstr xiaozhi-esp32-server
```

### Linux/Mac版本（build-local.sh）：
```bash
#!/bin/bash

echo "========================================"
echo "开始构建Docker镜像"
echo "========================================"

echo ""
echo "[1/3] 构建server-base镜像..."

if [ $? -ne 0 ]; then
    echo "构建server-base失败！"
    exit 1
fi

echo ""
echo "[2/3] 构建server镜像..."
docker build -t xiaozhi-esp32-server:server_latest -f ./Dockerfile-server .
if [ $? -ne 0 ]; then
    echo "构建server失败！"
    exit 1
fi

echo ""
echo "[3/3] 构建web镜像..."
docker build -t xiaozhi-esp32-server:web_latest -f ./Dockerfile-web .
if [ $? -ne 0 ]; then
    echo "构建web失败！"
    exit 1
fi

echo ""
echo "========================================"
echo "✅ 所有镜像构建完成！"
echo "========================================"
echo ""
echo "镜像列表："
docker images | grep xiaozhi-esp32-server
```

**使用方法：**
```bash
# Windows
build-local.bat

# Linux/Mac
chmod +x build-local.sh
./build-local.sh
```

## 🐛 常见问题

### 1. 构建base镜像时网络超时
**问题：** pip安装包时超时
**解决：** Dockerfile-server-base已经配置了阿里云镜像源，如果还是慢，可以：
```bash
# 使用代理或更换DNS
```

### 2. 构建web镜像时npm install失败
**问题：** npm下载包失败
**解决：** 修改 `main/manager-web/package.json` 或使用国内npm镜像

### 3. 构建web镜像时mvn构建失败
**问题：** Maven下载依赖失败
**解决：** 配置Maven使用国内镜像源

### 4. 镜像太大
**问题：** 镜像占用空间大
**解决：** 正常现象，server镜像包含Python和AI模型依赖，通常2-3GB

### 5. 修改代码后需要重新构建
**问题：** 修改代码后不生效
**解决：** 
- 重新构建镜像：`docker build -t xiaozhi-esp32-server:server_latest -f ./Dockerfile-server .`
- 或者使用Volume挂载（开发时推荐）

## 💡 开发建议

### 开发阶段（频繁修改代码）：
使用Volume挂载，无需重新构建：

构建镜像测试，确保所有依赖都正确打包

### 部署阶段（生产环境）：
使用构建好的镜像，保证环境一致性
